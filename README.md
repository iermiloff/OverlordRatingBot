# 🤖 OverlordRatingBot — Игровая Экосистема Активности Чатов

**OverlordRatingBot** — это промышленная CRM-платформа и игровой движок для автоматизации, геймификации и защиты Telegram-сообществ. Бот превращает обычное текстовое общение участников в экономическую стратегию: начисляет рейтинг за активность, рассчитывает несгораемые титулы по шкале опыта, управляет автоматическими лотереями по билетам и выжигает инфляцию через встроенный No-Code магазин мерча.

---

## 🛠️ Технологический стек ядра
* **Язык разработки:** Python 3.11+
* **Асинхронный фреймворк:** Aiogram 3.x (архитектура изолированных роутеров и кастомных Middlewares)
* **База данных:** PostgreSQL (транзакционный слой, асинхронный движок SQLAlchemy + AsyncPG)
* **Фоновый планировщик задач:** APScheduler (Time-Triggered архитектура автоматизации событий)
* **Математический анализ фрода:** NumPy (векторные вычисления стандартных отклонений)
* **Инфраструктура контейнеризации:** Docker / Docker-Compose

## 💎 1. Адаптивный экономический движок и геймификация

В платформу заложена уникальная игровая механика **«Бережливый накопитель vs Азартный игрок»**, которая регулирует инфляцию и мотивирует участников удерживать балансы:

* **Несгораемые Титулы (Ранги):** Текущий ранг пользователя в иерархии чата рассчитывается на основе его исторического опыта (`lifetime_rating`). Если пользователь тратит рейтинг в магазине или лотереях, его звание **никогда не понижается**, что полностью защищает игрока от психологического выгорания (тильта).
* **Экономический штраф за траты:** Прогресс-бар и счетчик опыта до следующего звания рассчитываются строго от актуального текущего кошелька (`current_rating`). Любая покупка товара или билета сдвигает планку получения нового титула назад, требуя проявлять активность заново. 
* **Групповой интерактив (`/stats`):** Команда заблокирована для использования в личке, чтобы не создавать кашу. При вызове в групповом чате она выводит стильную HTML-карточку со статистикой сообщений, балансом, рангом и визуальным индикатором пути прогресса. Для защиты от Flood-насилия серверов Telegram на команду установлен персональный локальный **кулдаун (задержка) в 10 минут**.

## 🎉 2. No-Code Календарь Розыгрышей и Сундуков

Экосистема автоматизирована фоновыми воркерами `APScheduler`, которые тикают каждую минуту и полностью исключают ручной труд модераторов:

* **Индивидуальные часовые пояса админов:** В меню настроек интегрирована динамическая сетка мировых таймзон. Менеджер один раз выбирает свой регион (на кнопках горит его реальное локальное время). При создании розыгрыша админ пишет время строго по своим наручным часам — бот сам сопоставляет смещение и переводит его в UTC сервера.
* **Календарная сетка очередей:** База данных поддерживает неограниченное количество параллельно запланированных лотерей на недели вперед. Админ имеет инлайн-панель, где может в один клик аннулировать любой будущий ивент до его анонса.
* **Комбинированные и открытые критерии:** Розыгрыш может требовать только Титул (вход бесплатный) или комбинацию «Титул + Лотерейный Билет». При бесплатном режиме у каждого участника ровно 1 равный шанс. При билетах — количество купленных билетов в инвентаре пропорционально умножает вес игрока в лотерейном барабане (банке шансов).
* **Честная лотерея:** После автоматического подведения итогов, у победителя **сгорают абсолютно все билеты данного типа**. У проигравших участников билеты **сохраняются**, позволяя кумулятивно копить массу и рано или поздно получить выигрыш.

## 🔒 3. Математическая система Анти-фрода (контроль ЦНС)

Для защиты игровой экономики от спам-скриптов, макросов на клавиатурах и кликеров, в ядро внедрен математический middleware-анализатор на базе библиотеки `NumPy`:

* **Суть алгоритма:** Обычный человек пишет сообщения хаотично (разброс таймингов велик). Роботы шлют текст по таймеру с микро-дрейфом. Бот собирает временные метки последних 15 сообщений юзера, рассчитывает интервалы в секундах и вычисляет их **стандартное отклонение (σ)** через `np.std()`.
* **Порог триггера:** Если стандартное отклонение интервалов падает ниже критического порога **3.5 секунд** при среднем времени отправки менее 45 секунд — система изолирует игрока.
* **Экстренные CRM-алерты:** Бот моментально блокирует начисление рейтинга нарушителю, маркирует профиль как `is_suspicious` и рассылает всем менеджерам в ЛС карточку математических метрик фрода с кнопками мгновенного перманентного бана (со сжиганием кошелька) или помилования в один клик.

## 🎨 4. Кастомизация и Брендирование (White-Label)

Платформа спроектирована по No-Code White-Label концепции. Вы можете полностью изменить визуальный стиль и экономику бота под ваш бренд, не меняя ни единой строчки бэкенд-кода. Вся кастомизация вынесена в конфигурационный файл `.env`:

* **Фирменный стиль валюты:** Переименуйте `CURRENCY_NAME` (например, `Лампы`, `Души`, `Монеты`) и задайте уникальный `CURRENCY_EMOJI`. Бот автоматически обновит весь интерфейс: от магазина до карточек `/stats` и логов лотерей.
* **Гибкая шкала рангов:** В переменной `TITLES` задается любая иерархия званий и пороги опыта. Вы можете сделать как классический RPG-стиль («Рекрут», «Рыцарь», «Лорд»), так и тематический под ваше комьюнити.
* **Медиа-витрина бренда:** В No-Code админке магазина вы можете загружать логотипы вашей компании, превью реального мерча (худи, кепки, девайсы) в виде сочных Фото или анимированных GIF-файлов, создавая полноценную брендированную витрину.

## 🛠️ Инструкция по первому запуску

### 1. Подготовка конфигурации
Скопируйте репозиторий и настройте шаблон переменных окружения в рабочий файл `.env`:
```bash
git clone https://github.com/iermiloff/OverlordRatingBot/
cd OverlordRatingBot
cp .env.example .env
```

### 2. Настройка файла `.env` (Whitelabel-брендирование)
Откройте файл `.env` любым текстовым редактором и заполните обязательные параметры:
```env
BOT_TOKEN=ваша_строка_токена_из_@BotFather
DATABASE_URL=postgresql+asyncpg://postgres:secret_pass@db:5432/rating_bot
MANAGERS_IDS=12345678,87654321 # Telegram ID менеджеров через запятую

BOT_NAME="Ваше Сообщество"
CURRENCY_NAME="EXP"
CURRENCY_EMOJI="💎"
SUPPORT_USERNAME="@manager_help"

REF_REWARD_RATING=50
REF_TARGET_RATING=200
RATING_PER_MESSAGE=1
COOLDOWN_MESSAGE_SEC=30

TITLES_CONFIG="1:Новичок:0;2:Активист:100;3:Гуру чата:500;4:Легенда:2000"
```

### 3. Запуск одной командой
Убедитесь, что на сервере установлен Docker, и выполните:
```bash
docker-compose up -d --build
```
*Система самостоятельно скачает образы, создаст изолированную базу данных и сгенерирует структуру таблиц в PostgreSQL. Бот готов к работе!*

## 🗺️ Карта навигации и структуры интерфейсов бота

Ниже представлена точная иерархическая структура инлайн-переходов, No-Code кнопок и командных путей всей экосистемы бота:

### 👤 1. Интерфейс Участника ЧАТА (Личный кабинет пользователя)

* **📱 Личные сообщения с ботом** ➔ Команда `/start`
  * 🛍️ **Магазин товаров (Shop)** ➔ Список активных позиций мерча / билетов
    * 💳 *Кнопка: Купить* ➔ Атомарное списание `current_rating` ➔ Запись в Inventory пользователя.
    * ↩️ *Кнопка: Вернуться в главное меню* ➔ Медиа-защита (зачистка фото-сообщений через delete).
  * 🎁 **Мои Награды (Заказы)** ➔ Просмотр купленного мерча или выигрышей
    * 📝 *Кнопка: Указать контактные данные* ➔ FSM-сценарий ввода реквизитов доставки.
  * 🤝 **Партнерская программа** ➔ Вывод уникальной реферальной ссылки пользователя.
  * 💬 **Наши Чаты** ➔ Отображение списка всех групп проекта со ссылками на вступление.
  * 🎖️ **Список Титулов** ➔ Справочная таблица всей иерархии званий экосистемы чата.

* **💬 Публичные групповые чаты проекта** ➔ Команды и триггеры активности:
  * `/stats` ➔ Вывод игровой HTML-карточки (Текущий ранг по `lifetime_rating`, прогресс по `current_rating`). На команду установлен жесткий **кулдаун в 10 минут** против флуда.
  * `[Отправка текстовых сообщений]` ➔ ActivityLog ➔ NumPy Antifraud Middleware (Проверка σ интервалов на кликеры).

---

### 👑 2. Пульт Управления CRM (Интерфейс Менеджеров и Оверлордов)

* **📱 Личные сообщения с ботом** ➔ Команда `/start`
  * 👥 **Список пользователей** ➔ Пагинация всей базы (Просмотр профиля, выдача/снятие пермабана в 1 клик).
  * 📦 **Настройка магазина** ➔ Панель No-Code управления ассортиментом товаров:
    * ➕ *Кнопка: Добавить товар* ➔ FSM: Название ➔ Описание ➔ Цена ➔ Фото/GIF ➔ Метка билета.
    * 🗑️ *Кнопка: Удалить товар* ➔ Мягкое логическое удаление (`is_deleted = True`) без сбоев истории покупок.
  * 📥 **Заявки/Заказы** ➔ Пагинация новых запросов на мерч/выигрыши от игроков (Фильтр по статусу `created`):
    * ✅ *Кнопка: Выполнено* / ❌ *Кнопка: Отклонить* ➔ Мгновенное пуш-уведомление победителю в ЛС.
  * 🔒 **Антифрод-система** ➔ Картотека ручного мониторинга подозрительных лиц (Фильтр по `is_suspicious == True`):
    * Изучение математических логов NumPy (Стандартное отклонение σ) ➔ Кнопки: 🔨 *Бан* / ✅ *Помиловать*.
  * ⚙️ **Настройка Чатов, Промо и Времени** ➔ Системная инфраструктура:
    * 🟢 *Инлайн-переключатели* ➔ Включение / Выключение учета начисления опыта в конкретной группе чата.
    * 📢 *Управление промо* ➔ Добавление / Удаление каналов для обязательной партнерской подписки.
    * 🌍 *Кнопка: Сменить МОЙ Часовой Пояс (Профиль)* ➔ Динамическая сетка смещений с реальным временем на кнопках.
  * 📦 **Настройка Сундуков** ➔ Управление секретными ивентами активности:
    * 🚀 *Кнопка: Отправить сундук сейчас* ➔ Принудительный моментальный выброс кнопки сундука во все чаты группы.
    * ⚙️ *Кнопки: Сменить цену ключа* / *🎖️ Выбрать требуемый титул для открытия сундука*.
    * ⏱️ *Кнопка: Настроить рандом-таймер* ➔ FSM: Окно гарантированного сна (ч) ➔ Окно рандомного разброса (ч).
    * ➕ *Кнопка: Добавить награду в пул* ➔ Ввод типа (Валюта/Вещь) ➔ Ввод номинала приза ➔ Ввод веса шанса выпадания.
  * 🎉 **Настройка Розыгрышей** ➔ Сетка автоматических календарных лотерей:
    * ➕ *Кнопка: Создать новый розыгрыш* ➔ Пошаговый конструктор: Приз ➔ Места ➔ Звание ➔ Билет (или Пропустить) ➔ Время анонса требований по вашим наручным часам ➔ Время финала.
    * 📋 *Календарь лотерей* ➔ Список будущих ивентов ➔ Кнопка: 🗑️ *Удалить лотерею №X* (Полное аннулирование из расписания).

### ⏱️ 3. Экстренные шлюзы алертов и триггеры автоматизации
* 🚨 **NumPy Antifraud Alert** ➔ Мгновенный пуш всем админам в личку при детекте кликера: Кнопка: 🔨 *Подтвердить Бан и Сжечь* / Кнопка: ✅ *Ложная тревога*.
* ⏰ **APScheduler Проверка** ➔ Фоновый ежеминутный воркер: Публикация анонсов требований ➔ Авто-финал лотерей ➔ Расчет весов билетов ➔ Авто-начисление рейтинга/мерча ➔ Полное сгорание билетов этого типа строго у победителей.
* 🏆 **APScheduler Доска почёта** ➔ Фоновый воркер раз в 24 часа: Сбор логов сообщений ➔ Авто-публикация Топ-10 активистов во все чаты.
