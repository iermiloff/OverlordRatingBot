# 💎 Telegram Whitelabel Rating System Bot

Современный асинхронный Telegram-бот для автоматического расчета рейтинга пользователей за их текстовую активность в группах. Включает встроенный магазин мерча, реферальную трекинг-систему, интерактивные мини-игры (Секретные сундуки, Розыгрыши) и суточную систему Анти-фрода.

Бот спроектирован по принципу **No-Code для персонала**: менеджеры могут изменять цены, требования к титулам, добавлять товары и партнерские ссылки прямо с экрана телефона в Telegram, без кодинга и SSH.

## 🚀 Архитектура и Стек
* **Ядро:** Python 3.11 + Aiogram 3.x (Асинхронные хэндлеры и FSM)
* **База данных:** PostgreSQL + SQLAlchemy 2.0 (Asyncpg драйвер)
* **Конфигурация:** Pydantic Settings v2 (Полный Whitelabel через `.env`)
* **Окружение:** Docker + Docker-compose (Изолированные контейнеры приложения и БД)

## 🛠️ Инструкция по первому запуску

### 1. Подготовка конфигурации
Скопируйте репозиторий и настройте шаблон переменных окружения в рабочий файл `.env`:
```bash
git clone https://github.com/iermiloff/OverlordRatingBot/
cd OverlordRatingBot
cp .env.example .env
```

### 2. Настройка файла `.env` (Whitelabel-брендирование)
Откройте файл `.env` любым текстовым редактором и заполните обязательные параметры:
```env
BOT_TOKEN=ваша_строка_токена_из_@BotFather
DATABASE_URL=postgresql+asyncpg://postgres:secret_pass@db:5432/rating_bot
MANAGERS_IDS=12345678,87654321 # Telegram ID менеджеров через запятую

BOT_NAME="Ваше Сообщество"
CURRENCY_NAME="EXP"
CURRENCY_EMOJI="💎"
SUPPORT_USERNAME="@manager_help"

REF_REWARD_RATING=50
REF_TARGET_RATING=200
RATING_PER_MESSAGE=1
COOLDOWN_MESSAGE_SEC=30

TITLES_CONFIG="1:Новичок:0;2:Активист:100;3:Гуру чата:500;4:Легенда:2000"
```

### 3. Запуск одной командой
Убедитесь, что на сервере установлен Docker, и выполните:
```bash
docker-compose up -d --build
```
*Система самостоятельно скачает образы, создаст изолированную базу данных и сгенерирует структуру таблиц в PostgreSQL. Бот готов к работе!*

## 📱 Карта Меню и Возможностей

### 👤 Личный кабинет Пользователя
1. **📊 Моя статистика** — Кошелек, общий опыт и автоматический расчет места пользователя в глобальном топе чата.
2. **🛍️ Магазин товаров** — Каталог мерча с постраничной пагинацией и пошаговым сбором данных доставки. При покупке баланс списывается, но несгораемый титул не теряется.
3. **🤝 Партнерская программа** — Персональная реферальная ссылка со счетчиками рефералов в ожидании (холде) и успешно активированных.
4. **🎖️ Список титулов** — Наглядный прогресс-бар по званиям.
5. **📝 Задания** — Список партнерских каналов для подписки с автоматической API-проверкой членства.
6. **🎁 Мои Награды** — Лента истории покупок и выигрышей с отслеживанием статусов отправки посылки менеджером.

### 💼 Панель Менеджера (Полный No-Code)
* **👥 Список пользователей** — Постраничный просмотр досье всей аудитории, ручная корректировка баланса и выдача бесплатных подарков от админа.
* **📦 Настройка магазина** — Пошаговое добавление товаров с клавиатуры бота и "мягкое" удаление старых позиций без нарушения истории заказов.
* **📥 Заявки/Заказы** — Очередь обработки покупок с кнопками переключения статусов и мгновенными авто-пушами клиентам.
* **🔒 Антифрод-система** — Экран разбора подозрительных лиц, совершивших аномальное количество действий за сутки. Санкции (бан/обнуление) в 1 клик.
* **🎁 Настройка Сундука / Розыгрышей** — Панель изменения стоимости ключа, требуемого титула для открытия, запуск лотерей и принудительный выброс интерактивного сундука в чаты.
* **⚙️ Настройка Чатов и Промо** — Модерация подключенных групп активности и мгновенное удаление/добавление рекламных промо-каналов.
